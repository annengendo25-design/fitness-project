# FITZONE – My HTML Fitness Project

## Project Brief

FitZone is a fictional fitness center website designed to encourage people to start and maintain a healthy and active lifestyle.

The website provides information about FitZone, its fitness services, and ways for visitors to get in contact. The landing page is designed to be simple, colorful, responsive, and easy to navigate.

The design focuses on:

* A clear and attractive landing page
* Easy navigation
* Simple and understandable content
* Fitness-related images
* Mobile-friendly design
* Accessibility for different users

## Technologies Used

* HTML – Used to create the structure of the website
* CSS – Used for styling, layout, colors, and responsive design
* Git – Used for version control
* GitHub – Used to store and manage the project
* GitHub Pages – Used to deploy the website

## Website Sections

### 1. Hero Section

Introduces FitZone and communicates the main value proposition of the fitness center.

### 2. Services Section

Provides information about the different fitness services offered by FitZone.

### 3. About Section

Explains what FitZone is and its purpose.

### 4. Contact Section

Includes a contact form that allows visitors to provide their information and send a message.

### 5. Footer

Contains copyright information and social media links.

## Features

## Accessibility

Accessibility was considered during development by including:

* Alternative text for images
* Semantic HTML5 elements
* Proper heading hierarchy
* Accessible form labels
* ARIA labels where appropriate
* Keyboard-friendly navigation

## Responsive Design

The website follows a mobile-first approach and is designed to work across different screen sizes, including:

* Mobile phones
* Tablets
* Laptops
* Desktop computers

The website is intended to work in Chrome, Firefox, and Safari.

## Setup Instructions

To run the project locally:

1. Clone the GitHub repository.
2. Open the project folder.
3. Locate the `index.html` file.
4. Open `index.html` in a web browser.

Alternatively, the project can be opened using Visual Studio Code and its Live Server extension.

## Deployment

The website is deployed using GitHub Pages.

The live website can be accessed through the GitHub Pages link provided in the repository.
